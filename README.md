# xss-scanner
XSS Скрипт для Проверки Уязвимостей на Сайтах  Этот скрипт предназначен для автоматической проверки сайтов на уязвимости XSS (Cross-Site Scripting). Он перебирает параметры URL и отправляет популярные payloads для выявления возможных уязвимостей, которые могут быть использованы для выполнения вредоносного JavaScript-кода.
